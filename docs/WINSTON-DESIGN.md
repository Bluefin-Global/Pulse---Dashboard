# Winston Command — approved design direction

Approved November 24, 2026. Two separate navigable screens sharing existing Firebase data and backend services. Command Center is the default landing screen.

## Command Center
Original approved reference: cinematic circular room, panoramic curved market displays, central floating dotted holographic Earth above circular pedestal, glossy reflective dark floor, electric blue/cyan and red-orange/magenta lighting. Live heat map, ticker, market intelligence and Winston AI.

## Trading Dashboard
Approved second concept from November 24: same cinematic room aesthetic, central spherical interactive firm/account network with orbiting nodes and illuminated pedestal, account overview and P&L and stock heat map on left, futures/options charts, order flow and tape speed on right, lower navigation controls, explicit Command Center / Trading Dashboard navigation. Use actual existing firm/account names and real connected data, never illustrative balances as live values.

## Acceptance criteria
No cartoon graphics, generic flat dashboard templates, or static backgrounds masquerading as working displays. Preserve existing authenticated financial functionality. Visual concepts are targets, not proof of implementation. Compare rendered previews to approved references before release. No production merge without approval.
